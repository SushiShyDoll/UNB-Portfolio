# UNB Portfolio (React + TypeScript + Vite)

    npm install
    npm run dev

- Edit members in `src/data/team.ts`. Each one gets a profile page at `/#/team/<id>` and an entry in the Our Team dropdown.
- Put images in `public/images` and The Seasons font in `public/fonts` (see the README.txt files there).
- Colours and fonts are CSS variables at the top of `src/styles.css`.
